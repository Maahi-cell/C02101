# C02101 - Lab 1: Linux Environment & Shell Scripting

This repository contains my solutions for the C02101 Lab 1 assignment. It covers fundamental Linux system commands, process inspection, and automation using Bash shell scripting.

## Completed Tasks
* `hello.sh` - Explores basic string outputs and built-in environment variables (`$USER`).
* `variables.sh` - Demonstrates assigning variables and performing basic mathematical arithmetic.

## How to Run the Scripts
Before running the scripts on a Linux or macOS terminal, ensure you grant them execution permissions:

```bash
chmod +x hello.sh
chmod +x variables.sh

# Run the hello script
./hello.sh
```
